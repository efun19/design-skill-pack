这是什么

两个 agent skill 的集合

Skill 01
brand-design-tokens
71 个真实品牌的设计 token 数据库。token 来源于 VoltAgent/awesome-design-md——从各品牌公开可见的 CSS 中提取， 涵盖颜色、字体、圆角、间距等设计决策，结构化为 Markdown，AI 可直接调用。
Skill 02
brand-slides
基于 frontend-slides 改造：在其零依赖、视口适配的基础上， 增加品牌 token 套用、风格预设选择、PDF 导出等 agent 工作流。 你正在看的这个页面，就是用它生成的。

两个 skill 可独立使用，也可组合——brand-slides 调用 brand-design-tokens 获取品牌 token。

为什么有这个项目

设计风格难以用语言描述

"我想要一个简洁的、现代的、专业的……"
  • 大多数人无法凭空描述设计风格——先看到，才知道自己想要什么
  • awesome-design-md 已有结构化的品牌 token 数据，frontend-slides 已有可用的幻灯片生成方案，缺的是把两者连接起来、让 AI 直接驱动的 agent 工作流
  • 把两个项目封装成 skill，AI 就能在对话中直接查询 token、套用风格、生成演示文稿，无需用户手动查文档或写代码
能做什么

四种典型用法

01
获取品牌设计 token
点名任意品牌，获取其完整的颜色体系、字体规格、圆角、间距等设计决策
02
生成品牌风格演示文稿
描述内容，套用品牌 token，输出可直接打开的 HTML 幻灯片，无需任何构建工具
03
多品牌设计对比
同一内容，用多套品牌设计系统渲染，直观感受不同设计语言的气质差异
04
设计系统灵感探索
浏览 71 套真实品牌，从产品级设计决策中汲取灵感，找到适合自己项目的风格

安装

将项目加入 Claude Code 工作区

克隆仓库，作为 Claude Code 工作目录打开，两个 skill 即自动可用。

Terminal
# 克隆仓库
git clone https://github.com/efun19/design-skill-pack

# 在 Claude Code 中打开
claude design-skill-pack/

# skill 自动加载，直接在对话中使用
如何使用

用自然语言描述，AI 处理其余一切

brand-design-tokens
"帮我看看 Stripe 的设计系统"
→输出颜色体系、字体规格、圆角尺寸、间距比例…… 所有设计 token，可直接应用于任何前端项目
"对比 Linear 和 Notion 的设计风格"
→生成两套品牌的并排对比预览，直观看出差异
brand-slides
"帮我做一个产品发布演示文稿，用 Linear 的风格"
→引导收集内容、选择风格、确定长度， 输出完整 HTML 演示文稿，自动在浏览器打开
"把这个演示文稿导出为 PDF"
→调用 Playwright 截图，合并为 PDF 文件
致谢 & 引用

站在开源项目的肩膀上

  • 01
    VoltAgent / awesome-design-mdMIT GitHub ↗
    一个品牌设计规范收录项目，将真实产品的设计决策（颜色、字体、间距、圆角） 从公开 CSS 中提取，以结构化 Markdown 格式保存。 本项目的 71 套品牌 token 全部来源于此，按分类整理后供 AI 直接读取调用。
  • 02
    frontend-slidesMIT GitHub ↗
    一个零依赖的 HTML 演示文稿生成方案：单一 HTML 文件，所有 CSS / JS 内联， 每张幻灯片严格适配 100dvh，禁止幻灯片内滚动。 brand-slides 在此基础上增加了品牌 token 套用、12 套视觉预设、PDF 导出和 agent 工作流。
