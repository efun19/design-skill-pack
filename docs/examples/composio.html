Built for developers

Designed for modern AI workflows — minimal boilerplate, maximal control. Here's what the API looks like:

# install
$ npm install @composio/sdk

# authenticate
import { Composio } from "@composio/sdk"

const composio = new Composio({
  apiKey: "sk_..."
})
# connect tools
await composio.tools.connect([
  "slack",
  "github",
  "gmail",
  "notion"
])
